# 全局画布界面去网格化与现代纯净卡片层叠体系 (Clean Minimalist Canvas & Elevation)

重构全局工作台与登录界面的底纹呈现，彻底废弃工程线框风格的网格线条（.landing-grid），采用纯净画布底色（Clean Minimalist Canvas）配合多层级微阴影（Multi-layer Elevation）与半透明微边框体系。

## Context

iRouter 原本在全局工作台布局（`DashboardLayout`）与登录页（`login`）中默认注入了 40px 的方格线条遮罩（`.landing-grid`）。在实际日常桌面端与 Web 端使用中，该网格视觉侵入性较强，带来了明显的工程草稿感、线框割裂感，分散了用户对核心模型与网关监控数据的专注度；且在不同显示器分辨率与缩放比例下，容易产生轻微莫尔条纹与视觉噪点。

## Decision

1. **彻底移除线性网格**：
   - 从 `DashboardLayout.js` 和 `login/page.js` 中彻底移除 `.landing-grid` 节点；
   - 在 `globals.css` 中将 `.landing-grid` 重构为零视觉噪点的平滑画布，消除所有高频线性方格；
2. **纯净底色与氛围漫射（Ambient Canvas）**：
   - 亮色模式依托温润象牙米白（`#FDFAF6`），暗色模式依托中性暖深黑灰（`#1a1a1a`）；
   - 在登录关键屏等独立聚焦场景辅以极低调的超微漫射光晕（Ambient Glow），赋予界面现代通透的纵深感；
3. **卡片浮层系统强化（Surface & Elevation）**：
   - 优化 `--shadow-soft` 与 `--shadow-elev` 为多层柔和漫反射阴影，使纯白/深色卡片在干净画布上自然立体浮起；
   - 边框采用高精细度的半透明微边框（Subtle Border），解决移除网格后卡片与背景间距感知弱化的问题；
4. **作为全局系统固化外观**：
   - 直接固化为系统默认 UI/UX 标准，不增加冗余的设置项开关，保持克制的设计哲学。

Status: accepted

## Considered Options

- **纯净现代无网格底色（选定）**：信息层级纯粹，去除一切干扰，彻底对齐 Linear / Vercel 现代极简设计。
- **微弱微点阵（Dot Matrix）**：相比方格有所减弱，但仍然在暗色与视网膜屏幕上产生细碎视觉噪点，不如纯净画布通透。
- **配置项开关切换**：增加设置复杂度与维护成本，未从根本上确立产品的统一设计语言。

## Consequences

- 全局所有页面视觉背景得到彻底净化，各仪表盘卡片与监控图表更加突出、清晰；
- 登录页与主控制台在亮暗两套主题下的美学表现更加一致、现代；
- 废弃了对旧线性背景规则的强依赖，减轻浏览器图层复合与渲染负担。
