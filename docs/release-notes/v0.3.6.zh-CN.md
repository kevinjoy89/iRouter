## 简体中文

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。
> 本版本（v0.3.6）完成了上游 9Router **`v0.5.95`** 基线源码的全量同步合并，显著提升了流式传输稳定性，引入了新模型能力与提供商适配，并进一步完善了自动化测试门禁。

### 🚀 新特性与基线同步 (What's New & Upstream Sync)

#### 1. 上游基线同步升级至 v0.5.95
- 同步合并上游 40 个提交与 137 个文件变更，网关核心基线版本升级至 `0.5.95`；
- 保持 ADR 0004 版本解耦设计，桌面端产品版本维持独立的 `0.3.6` 演进。

#### 2. OpenAI Responses 流式传输生命周期强化
- 引入流式终态 usage 等待机制，确保在获取到完整 Token 统计后再结算；
- 增加 3 秒看门狗定时器防挂起兜底，彻底杜绝极端异常网络下流式连接悬挂问题。

#### 3. 思考强度统一映射与自适应支持
- 统一 Claude / Kiro / Gemini / OpenAI 思考强度解析架构；
- 支持 Claude adaptive 模式及 `xhigh` 档位门控，并与本地 `effortCap` 思考上限钳制机制无缝融合。

#### 4. 新增模型与服务提供商适配
- **新增提供商**：Muse (Meta Model API)、Tinyfish、v1m / SystemOne 支持，增加 GLM OAuth 适配；
- **新模型支持**：引入 Claude Sonnet 5.5 / Opus 5.5 以及 Codex GPT-6 / 1M 扩展上下文模型；
- **CLI 工具增强**：新增 connect 命令工具链路并支持动态解析 API 密钥。

---

### 💎 本地专有核心能力 100% 完整保留

本项目特有的安全与可靠性定制特性已全部验证并保留：
- **出站数据脱敏 (DLP)**：严格审计并脱敏出站 Prompt，保障本地凭证安全；
- **智能重试退避 (`retryCfg`)**：兼顾客户端自定义重试策略与提供商错误规则过滤；
- **思考强度上限主动钳制 (`effortCap`)**：从前端请求到翻译层全面防止突发思考额度消耗；
- **Combo 跨模型容灾与应用内更新**：4xx 自动故障转移与桌面端平滑更新机制保持稳固。

## English

[Back to Top / 返回顶部](#top) | [简体中文](#chinese)

> **iRouter** is a cross-platform desktop client for the LLM router gateway based on [decolua/9router](https://github.com/decolua/9router).
> Release v0.3.6 synchronizes upstream 9Router **`v0.5.95`** baseline source code, enhancing streaming stability, introducing new model capabilities and provider adapters, and strengthening automated regression gates.

### 🚀 What's New & Upstream Sync

#### 1. Upstream Baseline Upgraded to v0.5.95
- Merged 40 commits and 137 file changes from upstream, bumping the gateway core baseline to `0.5.95`;
- Retained the ADR 0004 version decoupling design: desktop product version evolves independently at `0.3.6`.

#### 2. Enhanced OpenAI Responses Streaming Lifecycle
- Added terminal usage waiting mechanism to ensure accurate token settlement;
- Integrated a 3-second watchdog timer to eliminate hanging streams under unstable networks.

#### 3. Thinking Intensity Mapping & Adaptive Support
- Unified thinking effort parsing architecture across Claude, Kiro, Gemini, and OpenAI;
- Supported Claude adaptive mode with `xhigh` gating, seamlessly coupled with local `effortCap` clamping.

#### 4. New Models & Provider Integrations
- **New Providers**: Support for Muse (Meta Model API), Tinyfish, v1m / SystemOne, and GLM OAuth;
- **New Models**: Added Claude Sonnet 5.5 / Opus 5.5 and Codex GPT-6 / 1M extended context models;
- **CLI Enhancements**: Enhanced connect command tool suite and dynamic API key resolution.

---

### 💎 Custom Features 100% Preserved

All local security and reliability features remain active and verified:
- **Data Loss Prevention (DLP)**: Outbound prompt sanitization protects sensitive credentials;
- **Smart Retries (`retryCfg`)**: Client-side backoff and provider error categorization;
- **Thinking Effort Clamping (`effortCap`)**: Proactive ceiling enforcement across requests;
- **Combo Cross-Model Fallback & In-App Updates**: Resilient 4xx recovery and seamless desktop updating.
