# iRouter v0.4.6 Release Notes

[简体中文版本](https://github.com/kevinjoy89/iRouter/blob/v0.4.6/docs/release-notes/v0.4.6.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.6)

> **iRouter** is a cross-platform desktop client for LLM routing gateways, built on a lightweight Tauri v2 + Bun architecture.
> **v0.4.6 highlights**: usage and quota messages that had been stuck in English across both Chinese locales now display properly, the Traditional Chinese interface no longer mixes in Simplified glyphs, and several protocol and storage defects that could drop a request or corrupt stored data are fixed.

---

### 🌟 What's New

- **Full Chinese support in the quota tracker**: quota cards for OpenCode, Cursor, Command Code, Xiaomi MiMo, Kimi, Zed and others used to show raw English messages (for example, "no access to this API key"). They now display correctly in both Simplified and Traditional Chinese. Dynamic messages carrying an HTTP status code — such as "usage API error (503)" — are translated too;
- **Fixed Simplified glyphs leaking into Traditional Chinese**: over eight hundred Traditional Chinese entries had Simplified characters mixed in. One message read "这是…的机會", combining Simplified 这 / 机 / 会 with Traditional 金鑰 in a single sentence. All entries now use consistent Traditional forms, matching the conventions used in Taiwan;
- **Corrected the API key creation notice**: the key creation dialog claimed this was the only time the key would be visible. That was inaccurate — keys can be viewed and copied again from the list at any time — and the wording has been corrected;
- **Fixed successful responses masking upstream errors**: when a non-streaming request ended with an error frame from upstream, it was previously handed back to the caller as a success, producing an empty reply. It now returns the correct error status and reason;
- **Fixed Gemini tool call rejections**: Gemini and Antigravity requests carrying tools were rejected by upstream with a parameter validation error (400) when their argument schema contained nested arrays or objects. Request structures are now normalized, improving tool call success rates;
- **Safer token compression**: with token saving enabled, compression no longer rewrites the entire conversation, so Claude PDF documents, thinking blocks and tool call history survive intact. Gemini and Command Code tool output are now covered as well;
- **Fixed intermittent database write failures**: when a model name, endpoint or tool output contained a NUL byte, writing usage and request records would fail or silently lose the tail of the data. Such bytes are now stripped before writing;
- **Model search and bulk key import**: regular-expression searches in the model picker could skip models that should have matched, and bulk-pasting keys shaped like `LLM|id|secret` split them incorrectly, truncating both the name and the key. Both are fixed.
