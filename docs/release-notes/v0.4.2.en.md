# iRouter v0.4.2 Release Notes

[简体中文版本](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.4.2.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.2)

> **iRouter** is a cross-platform AI router gateway desktop client deeply tailored on top of [decolua/9router](https://github.com/decolua/9router) (powered by lightweight Tauri v2 + Bun architecture).  
> **v0.4.2 Highlights**: Reconstructed and streamlined shell settings modal (Plan A), extended comprehensive multi-language translations and dynamic regex internationalization across endpoints, combos, quotas, CLI tools, and System One, and strengthened prerendering build pipeline reliability.

---

### 🌟 Key Changes & Highlights

#### 1. Shell Settings Modal Refactoring (Plan A)

- **New "General" Section on Top**:
  - Consolidated previous "Appearance" and "Window" sections into the top navigation item;
  - Unified theme appearance, language preferences, and desktop window close/launch-at-login behaviors;
  - Prioritized "Follow system" as the default first option in theme selection.
- **New "Data & Logs" Section**:
  - Combined "Observability" and "Data Storage" into a single, cohesive view for console log switches, database storage metrics, retention days, and gateway configuration export/import.
- **Navigation Order Optimization**:
  - Restructured menu order: General → Network → Data & Logs → Security → Gateway Settings → Software Update;
  - Moved "Software Update" to the last position with persistent update badge notification.

#### 2. Comprehensive i18n & Dynamic Regex Localization

- **Endpoints & API Keys**:
  - Translated combo/model access control allowed badges (`Allowed for "..."`);
  - Added full localization for quick restriction confirmation dialogs (`Restrict API key "..."?`).
- **Combos & Vision Adapters**:
  - Translated batch selection actions and counters (`Select all (N)`, `N selected`);
  - Fixed skip-tag rendering issue on `<code>` blocks, translating context and max token metrics (`ctx ...`, `max ...`, `+N more`, `Auto — ...`);
  - Added localization for empty pool fallback notices (`No models in pool (will fallback to ...)`).
- **Quota Tracker & Usage**:
  - Localized countdown and expiration formats (`in Xd Xh Xm`, `expires in ...`);
  - Localized bonus and promo pack titles (`Bonus Pack N`).
- **CLI Tools & System One**:
  - Localized tool status indicators (`Checking ...`, `... not detected locally`, `... Configuration`);
  - Localized media and System One internal provider management descriptions.

#### 3. Production Build & Prerendering Fixes

- Resolved internal component import dependencies in settings modal, eliminating Next.js static prerendering export errors;
- All regression and i18n test suites passing (49/49).
