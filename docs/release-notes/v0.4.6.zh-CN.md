# iRouter v0.4.6 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/v0.4.6/docs/release-notes/v0.4.6.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.6)

> **iRouter** 是跨平台的大模型路由网关桌面客户端（Tauri v2 + Bun 轻量架构）。
> **v0.4.6 核心重点**：修复多语言界面中一直显示英文的用量与配额提示，修正繁体中文里混杂简体字的问题，并加固了几处会导致请求失败或数据异常的协议与存储缺陷。

---

### 🌟 核心变化

- **配额跟踪器全面支持中文**：OpenCode、Cursor、Command Code、Xiaomi MiMo、Kimi、Zed 等提供商的配额卡片此前直接显示英文提示（如「无权访问此 API 密钥」），现在简体与繁体界面都能正常显示；带 HTTP 状态码的动态错误信息（如「用量 API 错误（503）」）同样会翻译；
- **修复繁体中文混杂简体字**：繁体界面上千处文案此前混入了简体字形（例如「这是…的机會」一句里同时出现简体「这」「机」「会」与繁体「金鑰」），现已统一为规范的繁体用字，界面观感与台湾地区用字习惯一致；
- **修正 API 密钥创建提示**：密钥创建弹窗原先提示「这是您唯一一次看到此密钥的机会」，与实际行为不符——密钥在列表中随时可以再次查看与复制，文案已更正；
- **修复上游返回错误时仍显示成功**：非流式请求若上游以错误帧结束，此前会当作成功响应返回给调用方，得到一个没有内容的空回复；现在会正确返回错误状态与原因；
- **修复 Gemini 工具调用报错**：带工具的 Gemini / Antigravity 请求，其参数结构若含嵌套数组或对象，此前会被上游以参数校验错误（400）拒绝；现已按规范整理请求结构，工具调用成功率提升；
- **Token 压缩更安全**：开启 Token 节省功能时，压缩过程不再重写整段对话，Claude 侧的 PDF 文档、思考块与工具调用历史因此不会被破坏，同时新增对 Gemini 与 Command Code 工具输出的压缩支持；
- **修复数据库写入偶发失败**：当模型名、接口地址或工具输出中含有特殊空字节时，写入用量与请求记录会失败或丢失尾部数据，现已自动清理后正常写入；
- **模型搜索与批量添加密钥修复**：模型选择框中使用正则表达式搜索时会漏掉本应匹配的模型；批量粘贴形如 `LLM|id|secret` 的密钥时会被错误拆分，导致名称与密钥残缺——两处均已修正。
