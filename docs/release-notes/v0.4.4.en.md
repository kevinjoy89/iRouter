# iRouter v0.4.4 Release Notes

[简体中文版本](https://github.com/kevinjoy89/iRouter/blob/v0.4.4/docs/release-notes/v0.4.4.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.4)

> **iRouter** is a cross-platform desktop client for an LLM routing gateway (lightweight Tauri v2 + Bun architecture).
> **v0.4.4 highlights**: fully aligned with upstream 9router `v0.5.104` gateway baseline, adding Nous provider support and protocol compatibility enhancements; stabilized settings modal height and streamlined quota card layout; and comprehensively completed multi-language translations.

---

### 🌟 What's Changed

- **Upstream gateway baseline aligned with v0.5.104**: upgraded the underlying gateway baseline from `v0.5.99` to `v0.5.104`, incorporating upstream protocol improvements and security updates. Product version (v0.4.4) and upstream baseline (v0.5.104) continue to evolve independently and decoupled, preserving desktop self-developed enhancements cleanly;
- **Nous provider support**: integrated upstream support for Nous, including OAuth authorization, capability parsing, model routing, and usage tracking;
- **Upstream model protocols and routing enhancements**: synchronized upstream improvements for Claude (context management and empty thinking block normalization), Cursor (agent request proxying and usage tracking), OpenCode, and Vertex location routing, alongside enhanced model search filtering and deduplication;
- **Stable settings panel height**: refactored the settings modal to a unified, fixed height so that switching between General, Network, Security, and other submenus no longer causes the dialog to resize or bounce vertically; navigating to a new section automatically resets content scroll back to the top;
- **More compact quota list layout**: quota cards now display 3 items per page by default, and the bottom pagination toolbar has been streamlined into a single line with icon buttons, saving vertical screen real estate;
- **Clearer usage chart labels**: usage charts now accurately identify and display friendly names for custom nodes and compatible providers; long model names in the top models chart no longer clip and now wrap smoothly with left alignment;
- **Comprehensive multi-language translations**: added missing translations across breadcrumbs, quota reset periods, context compaction banners, service badges, and provider cards, eliminating leftover English and dynamic fragment concatenation.
