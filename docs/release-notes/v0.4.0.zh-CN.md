# iRouter v0.4.0 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.4.0.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.0)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。
> **v0.4.0 是桌面壳层的换代版本**：把笨重的 Electron 壳换成 **Tauri v2（Rust）+ Bun sidecar**，
> macOS 安装包从 **139.65 MiB 降到 46.5 MiB**（−66.6%），**功能全数保留**，含应用内更新。
> 网关源码零改动，仍与上游保持 merge 血缘。

---

### 🎯 本版本的核心变化：换壳

#### 1. 壳层：Electron → Tauri v2（Rust）

原来的壳是 Electron——它自带一整套 Chromium（仅 `Electron Framework` 二进制就 192 MiB）。
新壳用 **Tauri v2**：渲染交给**系统 webview**（macOS 的 WKWebView、Windows 的 WebView2、Linux 的 WebKitGTK），
壳本体变成一个几 MiB 的 Rust 二进制。

#### 2. 网关运行时：Electron 内置 Node → 随包分发的 Bun

原方案复用 Electron 自带的 Node 跑网关。新方案把 **Bun 作为 sidecar 随包分发**，哈希锁定在仓库内
（`tools/bun-pin.json`，五平台）。这是体积账的关键一步：选 Node SEA 的话，同样的换壳只能到约 79 MB——
会越过我们给自己定的 70 MB 线。

#### 3. 体积对比（实测，非估算）

| | Electron（v0.3.7） | **Tauri + Bun（v0.4.0）** |
| :--- | ---: | ---: |
| macOS (Apple Silicon) dmg | **139.65 MiB** | **46.5 MiB** |
| 安装后体积 | ~324 MiB | ~150–180 MiB 量级 |

### ✅ 功能对齐（一个不落）

换壳不等于砍功能。以下全部在新壳上重新实现并通过验证：

- **窗口与面板**：启动后等待网关就绪再显示，避免白屏；面板守卫令牌防浏览器直连
- **系统托盘**：左键唤出、右键菜单、双击、tooltip、模板图随菜单栏深浅色自动反色
- **原生菜单**：macOS 应用菜单（含 Edit，Cmd+C/V/X/A 依赖它）、帮助菜单
- **关闭行为**：`closeAction` 三档（quit / dock / tray）与设置面板联动
- **开机自启**：与系统实际状态双向同步
- **单实例**：第二次启动唤出已有窗口，不重复起网关
- **应用内更新**：检查 / 下载（带进度与取消）/ 校验 / 调起安装器，**与 0.3.x 完全同一套行为**
- **原生对话框**：「检查更新」的结果与失败提示
- **多语言**：菜单与对话框的 en / zh-CN / zh-TW

#### 关于孤儿进程（换壳时最容易出事的地方）

网关是 shell 的子进程，**壳死了网关不能活着**——否则它会一直占着 `127.0.0.1:20128`。
新壳管理三条死亡路径，均有真机实测记录：

| 路径 | 行为 |
| :--- | :--- |
| 正常退出（托盘「退出」/ 菜单退出） | 按**进程树**回收网关，清理 PID 文件 |
| 收到 `SIGTERM` / `SIGINT` | 走同一条回收路径（对齐 Electron 版的信号处理） |
| 关窗到托盘（dock 档） | 网关继续服务，符合预期 |
| **上次异常退出留下的孤儿** | **下次启动时按 PID 文件回收**，不会永久占用端口 |

### 📦 升级方式

**如果你是 0.3.x 用户：直接在应用内检查更新即可**，无需手动下载。

新版本的资产命名与 0.3.x **逐字保持一致**（`iRouter-<版本>-<平台>-<架构>.<扩展名>`），
这是刻意保证的——老版本的自动更新靠**字符串全等**匹配资产名，改名会切断所有老用户的更新通道。
仓库里有三层断言守着这条规则。

升级后你会**换成一个全新的应用**（壳换了），首次打开时 macOS 可能要求你确认一次（因签名方式）。

### ⚠️ 已知限制

- **首次打开的系统提示**：安装包使用 ad-hoc 签名（未购买开发者证书）。macOS 上首次打开需
  右键「打开」或到「系统设置 → 隐私与安全性」放行一次。
- **Windows / Linux 未做真机验收**：CI 每轮四平台构建并做包内冒烟（验证 sidecar 在包里、
  网关负载在包里、最低系统版本正确），但**没有"装上去跑一遍"**。macOS 的真机验收抓到了一个
  CI 永远抓不到的缺陷（托盘图标显示为白板），因此其他平台若有类似问题，欢迎反馈。
- **macOS 最低版本 13.0**：这是随包分发的 Bun 二进制本身的要求，非本项目的选择。
- Linux 的 `.deb` 会声明 `webkit2gtk` 依赖（系统 webview，Tauri 的必需依赖）。
