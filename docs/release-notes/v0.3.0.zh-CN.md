# iRouter v0.3.0 发版说明 (Release Notes)

[English Version](v0.3.0.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.0)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。本版本将网关核心基线升级至上游最新稳定版 **v0.5.81**，同时引入针对多操作系统与芯片架构的跨平台自动化打包构建矩阵，并在开源合规、项目文档与工程依赖方面进行了系统性规范。

---

### 🌟 核心更新亮点 (What's New in v0.3.0)

#### 1. 🌐 网关核心基线升级至 v0.5.81
- **全量吸收上游核心改进**：同步来自官方 9Router **v0.5.81**（涵盖 100+ 个提交）的全部网关特性。
- **Xiaomi MiMo 桌面端生态集成**：适配小米 MiMo 桌面应用登录会话流程及专属模型调度。
- **Claude Code 1M 上下文增强**：支持 Claude Code 1M 上下文标记、Token 统计与流式拒绝帧优雅捕获。
- **DeepSeek V4.1 Flash 支持**：全面接入并适配 DeepSeek-V4.1-Flash 模型的视觉能力与长上下文映射。
- **OpenCode 稳定性与反拦截优化**：修复免费池频繁 403 拦截、429 会话重试及推理思维链（reasoning）历史加密字段污染问题。

#### 2. 🏗️ 标准化多平台构建矩阵 (Multi-Platform Build Matrix)
- **多平台自动化打包**：全面接入 GitHub Actions 矩阵构建，支持细分 CPU 架构与主流发行格式：
  - **macOS**：提供 Apple Silicon 原生架构（`arm64.dmg`）与 Intel 架构（`amd64.dmg`）。
  - **Windows**：提供标准 NSIS 向导安装包（`installer.exe`）与绿色便携版免安装包（`portable.zip`）。
  - **Linux**：提供 Debian/Ubuntu 系统原生软件包（`amd64.deb`）与通用便携压缩包（`amd64.tar.gz`）。
- **统一完整性校验**：所有发行产物随 Release 自动生成并附带 `checksums.txt`，供用户比对 SHA-256 校验和。

#### 3. ⚖️ 开源合规与文档规范化
- **双重协议保障**：在仓库根目录规范化确立 **MIT 许可证**，严格保留上游开源著作权与衍生项目许可说明。
- **中英双语文档**：重构并提供官方中英文双语 [`README.md`](../../README.md) 与 [`README.zh-CN.md`](../../README.zh-CN.md)。
- **社区鸣谢致谢**：在文档与应用关于页中正式增补对 `decolua/9router` 与 `momijineko/llm-retry-proxy` 的架构灵感与社区致谢。

#### 4. 🪶 轻量化工程整改与桌面聚焦
- **彻底剔除 Docker 及发布流水线**：移除历史残留的 Dockerfile、docker-compose 及镜像发布工作流，消除桌面客户端不必要的构建开销，全面专注于轻量、即开即用的跨平台桌面应用体验。

### 💎 本地专有核心能力完整保留

- 🔄 **智能限流重试与弹性容错 (ADR 0004/0005)**：
  - 在流式首字节（TTFT）到达前，自动拦截网络抖动及限流错误（`429`、`503`、`529`），并触发带抖动的指数退避重试。
  - 支持账号原地重试、粘性优先重试与 429 动态冷却锁定，有效解决命令行 Agent 瞬间限流报错闪退的痛点。
- 🛡️ **出站请求敏感信息脱敏 (DLP - Data Loss Prevention, ADR 0005)**：
  - 转发前动态检测并改写请求体中的 API Keys、私钥证书、身份证号、银行卡号等敏感信息。
  - 严格保持 Fail-Open 设计保证，绝不因脱敏规则评估异常而阻断正常通信；内置代码语境误报压制策略。
- 📊 **用量全量留存与实时滚动刷新**：
  - 请求明细全量持久化至 SQLite 数据库，软件重启与更新发版不丢记录。
  - 默认提供近 24 小时动态滚动窗口与高频自动刷新，支持状态码精准筛选。
- 📜 **高性能虚拟滚动控制台日志**：
  - 基于变高虚拟滚动组件重构日志呈现层，海量日志渲染依旧流畅不卡顿。
- 🔒 **数据目录安全隔离**：
  - 核心配置与 SQLite 数据库持久化于 `~/.irouter`，与应用缓存和系统安装包完全隔离。
  - 首次运行内置安全迁移向导，可一键将旧版 CLI `~/.9router` 配置无损导入。

### 📋 完整版本演进历史（项目诞生至 v0.3.0）

#### 🚀 v0.3.0 (2026-09-23) — 发版
- **上游基线全量同步**：合并 9Router 官方 **v0.5.81** 升级（支持 Xiaomi MiMo 桌面端、Claude Code 1M 上下文标记、DeepSeek-V4.1-Flash、OpenCode 403/429 稳定性修复等）。
- **标准化多平台构建矩阵**：引入 GitHub Actions 自动化流水线，全面支持细分芯片架构与多发行格式（`macos-arm64`、`macos-amd64`、`windows-amd64-installer`、`windows-amd64-portable`、`linux-amd64.deb`、`linux-amd64.tar.gz`）及统一校验和文件 `checksums.txt`。
- **开源合规与规范化**：补齐 MIT 双重许可声明、中英文双语 README 说明及明确致谢鸣谢。
- **轻量化工程整改**：彻底剔除 Docker 及容器化流水线，专注于桌面原生开发与分发。

#### ⚡ v0.2.6 ~ v0.2.10

- **v0.2.8**：修复流式请求 Token 统计与 TTFT 首字延迟结算遗漏问题。
- **v0.2.7**：优化请求详情错误排障明细与分页多语言体验。

#### 🛡️ v0.2.0 ~ v0.2.3

- **v0.1.6**：重构桌面架构，彻底清理主进程多余外挂，转为纯净的前端原生实现。

#### 🧩 v0.1.0 ~ v0.1.5

### 🔌 API 端点与本地配置

iRouter 桌面面板与 OpenAI 兼容 API 共享本地端口：

```text
API 端点:  http://127.0.0.1:20128/v1
API 密钥:  直接在 iRouter 桌面控制面板中点击复制
```
*端口顺延机制：若 20128 端口已被外部占用，iRouter 会自动顺延至下一个可用端口（如 20129），绝不强杀外部进程。*
