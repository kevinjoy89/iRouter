# iRouter v0.4.3 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/v0.4.3/docs/release-notes/v0.4.3.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.3)

> **iRouter** 是跨平台的大模型路由网关桌面客户端（Tauri v2 + Bun 轻量架构）。
> **v0.4.3 核心重点**：把上一版没落到实处的几件事收拾干净——设置入口真正装得上、全新安装跟随系统语言；同时修掉外链点不动、深色任务栏上看不见托盘图标、以及 Windows 安装程序的图标与语言。

---

### 🌟 核心变化

- **部分升级后界面没变**：上一版新增的设置入口，装在 Windows / Linux 上却看不到，而且控制台没有任何报错。原因是网关的页面缓存不随构建失效——覆盖安装后浏览器仍拿到旧界面。现在网关启动时会按构建标识清掉过期缓存，新界面立即生效；
- **全新安装的首启界面语言**：以前不跟随系统、固定为英文。现在三个平台统一按「**显式选择 > 系统语言 > 英文**」判定，菜单与面板不会再出现两种语言；
- **可选语言收敛**：语言选项收敛为简体中文 / 繁體中文 / English 三种（此前列表里有 28 种没有对应字典，选中会静默变成全英文）；
- **设置入口位置**：从顶栏右上角移到**侧边栏底部**并带上文字标签；托盘菜单的「设置…」同时提到第一位；
- **提供商详情页与「添加自定义模型」面板的漏译**：这两处残留的英文（含卡片标题、输入框占位提示）补齐为中文；
- **外链点击**：提供商详情页里的各种站外链接以前点了没反应，现在统一交给系统浏览器打开，应用窗口自身不跳转；
- **托盘图标**：Windows 深色任务栏与 Linux 面板上几乎看不见图标，已按平台取色修正；
- **安装体验（Windows / Linux）**：Windows 安装包与卸载器换回应用图标（此前是安装器自带的默认图标）；安装向导按系统语言自动使用中文；安装器底部版权行不再糊；运行时不再多弹一个黑窗；Linux 启动器里显示的应用名称与简介改为面向用户的说法。

---

> **校验**：本页附件 `checksums.txt` 含各平台安装包的 SHA-256 校验和；下载后可比对。
