# iRouter v0.3.2 发版说明 (Release Notes)

[English Version](v0.3.2.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.2)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。本版本将网关核心源码基线推进至官方 **v0.5.91**，全面解决 Claude 在 OpenAI 格式客户端中的思维链返回问题、补齐 Responses API 终态输出、增强 Gemini 边界防御与超大连接池 O(1) 高并发调度，同时无缝集成 Zed IDE 凭证导入，坚决剔除商业推广入口，保持客户端的纯净与专注。

---

### 🌟 核心更新亮点 (What's New in v0.3.2)

#### 1. 🌐 网关核心基线升级至 v0.5.91（去芜存菁，纯净专注）
- 全量吸收官方 9Router **v0.5.87 ~ v0.5.91**（覆盖 50+ 提交），显著提升各大主流模型供应商在长会话与高并发场景下的调度稳定性。
- **坚决排除商业推广内容**：彻底阻断 9Remote / 9English 商业推广入口与徽标，移除无关 Docker 流水线与冗余外部文档，保持 iRouter 桌面端轻量、纯净、无打扰。

#### 2. 🧠 Claude 思考内容在 OpenAI 格式客户端完整返回
- 修复并优化 Claude 响应在 OpenAI 兼容模式下的思维链转换链路。
- 完整输出 `reasoning_content`，彻底解决第三方 OpenAI 客户端（如 Cherry Studio、Chatbox 等）调用 Claude 时收不到完整思考过程的问题。

#### 3. 📦 Responses API 格式增强与 message.output 终态流式输出
- 深度对齐 Responses API 规范，补齐 `message.output` 终态流式输出与块格式封装。
- 解决下游依赖 Responses 协议的高级客户端在流式接收最后一块数据时断流或缺少终态标识的问题。

#### 4. 🤖 Gemini 末尾轮次空内容卫语句防御
- 在 Gemini 消息转换层针对末尾轮次的空消息或空内容添加严密卫语句检查。
- 杜绝因客户端误传末尾空文本引发的转换异常或上游 `400 InvalidArgument` 报错，大幅增强容错韧性。

#### 5. ⚡ 大连接池 O(1) 调度性能优化
- 针对连接池管理与高并发连接调度，重构核心连接存储结构，由原本的线性扫描优化为高效的哈希/双向索引结构。
- 插入与查找时间复杂度降低至 $O(1)$，在高吞吐、大连接池及长生命周期流式会话场景下 CPU 开销与延迟显著降低。

#### 6. 🔑 Zed IDE 凭证自动导入与生态集成
- 内置对 Zed 编辑器凭证配置的自动检测与无缝导入机制。
- 开发者可一键复用 Zed IDE 中的模型配置与 Token，免除重复配置密钥的繁琐步骤。

#### 7. ⏳ Claude 限流时间重置优化与免登账号池自动重置
- 接入上游最新 rate limit reset 响应时钟机制，精准识别 Claude 官方重置窗口。
- 配合免登账号池的自动刷新与智能复位，最大化提升可用配额与故障恢复效率。

#### 8. 🔮 GPT-6 Sol/Luna 等前瞻与新模型规格支持
- 预先注册并规范化 GPT-6 Sol、GPT-6 Luna 等前瞻模型规格与端点映射。
- 扩展对各类新型开源及专有推理模型的上下文窗口与计费倍率识别。

#### 9. 💎 本地专有核心能力 100% 完整保留
- **智能重试与退避机制**：保留 `retryCfg`（支持禁用指数退避与自定义冷却时间），提升弱网抗抖动能力。
- **出站数据脱敏 (DLP)**：严格保障出站数据安全过滤，敏感信息不外泄。
- **思考强度主动钳制 (`effortCap`)**：支持下游请求思考强度钳制，防止模型超额开销。
- **Combo 跨模型 4xx 容灾**：单模型 4xx 不阻断多模型容灾重试。

#### 🛡️ v0.2.0 ~ v0.2.3
- OpenCode 免费端点风控拦截防御、自定义提供商配置、Combo 元数据解析及用量拓扑动效图视口漂移缺陷修复。

- 桌面壳层设置面板模态框、出站请求敏感信息脱敏 (DLP) 引擎、版本号解耦（ADR 0004）、完整异常日志开关。

### 🔌 API 端点与本地配置

iRouter 桌面面板与 OpenAI 兼容 API 共享本地端口：

```text
API 端点:  http://127.0.0.1:20128/v1
API 密钥:  直接在 iRouter 桌面控制面板中点击复制
```
*端口顺延机制：若 20128 端口已被外部占用，iRouter 会自动顺延至下一个可用端口（如 20129），绝不强杀外部进程。*
