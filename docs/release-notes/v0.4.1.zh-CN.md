# iRouter v0.4.1 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.4.1.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.1)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端（采用 Tauri v2 + Bun 轻量架构）。  
> **v0.4.1 核心重点**：将底层网关基线全面升级至 9Router **v0.5.99**，引入细粒度 API Key 访问控制与 MiniMax Code 新渠道适配，并在完全保留本地专有特性（DLP 脱敏、智能重试、思考强度钳制）的前提下实现 CI/CD 自动化全平台全绿。

---

### 🌟 核心变化与亮点

#### 1. 网关基线全面升级至 9Router `v0.5.99`

- **细粒度 API Key 访问控制（KeyAccessControls）**：
  - 支持按 API Key 限制可调用的 Combo 组合及具体模型列表；
  - 覆盖 `/v1/chat/completions`、`/v1/messages`、`/v1/responses`、多模态端点及模型目录发现接口；
  - 鉴权前置在旁路与凭证查询之前，拒绝未授权访问的同时保持允许 Combo 的内部故障转移。
- **新增 MiniMax Code 与 MiniMax Code Global 渠道**：
  - 支持 MiniMax 开发者凭证与 OAuth 认证协议，原生对接 Anthropic 协议与代码补全能力；
  - 自动注入 Mavis 会话标识与本机时区偏移，支持自适应思考强度映射（`claude-adaptive`）。
- **扩展提供商生态**：
  - 新增 Kimchi 聚合接入与 OAuth 鉴权适配，支持推理内容去冗余；
  - 新增 Self-hosted TTS 自建语音合成引擎支持与界面占位提示；
  - 增强 Gemini / Claude / Responses 嵌套思考协议融合。
- **上游缺陷修复与边界强化**：
  - 修正 GLM-5.3 系列默认 1M 上下文窗口与思考禁用防御；
  - 修正 Cursor 实时模型目录探测与故障兜底容错机制；
  - 优化 CLI connect 工具配置同步与模型继承策略。

#### 2. 本地专有定制 100% 保留与深度融合

- **出站 DLP 敏感信息脱敏**：出站数据实时合规扫描与规则脱敏，拦截规则实时拦截，请求级日志完整审计；
- **智能重试与退避机制（autoRetry）**：对上游限流（429）、暂时性错误（500/502/503/504）及文本限流提示实施指数退避智能重试，保障 Agent 调用高可用；
- **思考强度主动钳制（effortCap / capped）**：融合上游 Claude `minimal -> low` 映射，叠加本地配置的最大思考深度主动钳制；
- **全量用量与请求明细留存**：保持历史全量调用记录与元数据，支持独立子进程后台清理与增量空间回收；
- **纯净体验保障**：坚决阻断任何 9Remote 推广外链与打赏弹窗，侧边栏保持极简专注。

#### 3. 跨平台门禁与自动化回归保障

- 针对单测环境完全隔离 HTTP/2 外部网络连接，消除真实连接依赖与超时风险；
- 隔离 Linux 下的 `XDG_CONFIG_HOME` 环境变量，保障多平台回归门禁稳定可靠；
- GitHub Actions CI/CD 流水线（Regression Gate、Windows / macOS / Ubuntu 构建）全量 100% 通过。

### 🚀 升级方式

1. **应用内自动更新（推荐）**：  
   已安装旧版本用户只需点击托盘菜单「检查更新...」，系统将自动检测 `v0.4.1`，下载后一键重启升级（资产名与现有更新器完全兼容）。
2. **全新安装**：  
   前往 [GitHub Releases](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.1) 下载对应平台安装包安装即可。
