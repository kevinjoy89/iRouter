# iRouter v0.3.5 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.3.5.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.5)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。本版本是 v0.3.4 之后的缺陷修复版：补齐设置面板里漏翻的若干文案，并修掉一个会让整个面板白屏的崩溃。

---

### 🛠️ 缺陷修复 (Fixes)

#### 1. 「下载中」等界面文案补齐多语言
- **现象**：设置面板在下载更新时显示英文 `Downloading update...`，其余语言环境下也一样。
- **根因**：这句是写死的 JSX 文本，运行时多语言字典里**没有对应条目**（字典按精确匹配翻译，缺条目即原样显示英文）。
- **修复**：顺着这条线索把设置面板整体扫了一遍，除 `Downloading update...`（正在下载更新…）外还揪出两处同类漏网——可观测性保存失败的提示、以及壳层设置读取中的占位文案，全部入典（简体中文 / 繁体中文）。
- **加固**：字典覆盖率守卫此前只认「被换行包着」的 JSX 文本，同行写法的按钮/状态文案会整片逃出检查——这正是本次漏翻的来源。已补同行抽取规则，并用变异测试确认：删掉字典条目后守卫立刻报错。

#### 2. 修「窗口 / 软件更新」分段白屏
- **现象**：打开设置面板时若直接落在「窗口」或「软件更新」分段（或面板刚打开、壳层设置还没读回来时切过去），整个面板白屏。
- **根因**：这两段读的是异步取回的壳层设置，而分段渲染分支没有像左侧导航那样做「是否就绪」判断，于是把尚未取回的 `null` 传了下去。
- **修复**：渲染与导航改用同一判据，未就绪时显示占位文案而不是崩溃。

### 🧰 工程改进 (Engineering)

- **发布流水线自动化**：打 tag 触发构建后，GitHub Release 的**标题与发版说明由流水线自动带上**（说明取自本仓库 `docs/release-notes/v<版本>.zh-CN.md`）。此前需要发布后手工补写正文——v0.3.3 与 v0.3.4 都是这么补的；现在说明文件缺失会直接让流水线报错，不再产出空正文的 Release。
- **CI 门禁稳定化**：`usage-dispatch` 用例动态加载的模块图较大，并发执行时可能超过默认超时并被误报为回归，已加显式超时。

智能重试与退避（`retryCfg`）、出站数据脱敏（DLP）、思考强度钳制（`effortCap`）、Combo 跨模型 4xx 容灾，全部原样保留。
