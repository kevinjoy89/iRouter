# iRouter v0.4.5 Release Notes

[简体中文版](https://github.com/kevinjoy89/iRouter/blob/v0.4.5/docs/release-notes/v0.4.5.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.5)

> **iRouter** is a cross-platform desktop routing gateway for Large Language Models (powered by Tauri v2 + Bun lightweight runtime).
> **v0.4.5 Highlights**: Introduces dedicated LLM latency & throughput speedtesting with native monotonic clock precision, integrates authoritative real-time model pricing from models.dev with an independent Integrations settings section, and improves usage chart label wrapping and settings visual hierarchy.

---

### 🌟 Key Changes

- **Dedicated LLM Speedtest & Benchmark Suite**: Added a standalone benchmark workbench supporting single-run and concurrent stress tests across providers and models; leverages a native high-precision monotonic clock to accurately measure TCP connection latency, Time to First Token (TTFT), generation tokens/second, and total duration;
- **Direct Route Intelligent Proxy Bypass**: The speedtest engine automatically identifies RFC 1918 private subnets (e.g., 10.x, 172.16-31.x, 192.168.x) and local loopback addresses, automatically bypassing system proxies for direct dedicated endpoints and eliminating false 502 Bad Gateway reports;
- **Integrated Real-Time models.dev Pricing**: Replaced manual rate editing with automatic synchronization from the official models.dev catalog, featuring adaptive 24-hour background refreshes and one-click manual sync; includes multi-tier fallback resolution with offline static snapshots;
- **New Standalone "Integrations" Settings Section**: Elevated external ecosystem integrations (such as model pricing) into a dedicated top-level settings card displaying data sources, tracked model counts, and sync timestamps, keeping core gateway settings focused on routing and safety;
- **Greedy Line Wrapping for Popular Models Chart**: Overhauled the label wrapping algorithm to prioritize filling each line up to capacity while intelligently preserving version decimal points (e.g., 3.0, 4.1), coupled with a widened Y-axis for enhanced readability;
- **Settings Interaction & Localization Improvements**: Fixed the selection state for the "System Default" locale option in the settings dropdown, and standardized heading hierarchy and spacing across settings panels for greater visual consistency.
