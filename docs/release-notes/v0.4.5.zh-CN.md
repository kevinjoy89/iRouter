# iRouter v0.4.5 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/v0.4.5/docs/release-notes/v0.4.5.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.5)

> **iRouter** 是跨平台的大模型路由网关桌面客户端（Tauri v2 + Bun 轻量架构）。
> **v0.4.5 核心重点**：新增专有大模型基准测速（Speedtest）与性能指标分析，全面接入 models.dev 权威实时定价与外部集成设置，优化图表标签换行及设置排版交互。

---

### 🌟 核心变化

- **新增专有基准测速（Speedtest）功能**：新增独立测速工作台，支持单次与批量并发压测各大上游提供商与模型；基于原生高精单调时钟，精准呈现网络连接延迟、首字响应延迟（TTFT）、每秒 Token 生成速率与总耗时；
- **专线直连智能旁路代理**：测速引擎自动识别局域网私有地址（如 10.x、192.168.x、本地回环），自动旁路系统代理直连专线端点，杜绝内网专线被误报为 502 错误；
- **全面接入 models.dev 权威实时定价**：彻底告别繁琐的手动编辑模式，直接与 models.dev 官方费率库保持实时同步，支持 24 小时自适应静默更新与一键手动刷新；具备多层级匹配与离线兜底机制，离线时仍可稳定估算费用；
- **设置面板新增「外部集成」独立分段**：将模型定价等第三方生态能力提升为独立的顶级设置卡片，集中展示数据来源、收录模型总数与最后同步时间，网关基础设置更聚焦核心路由与安全策略；
- **使用统计图表热门模型换行优化**：改进热门模型名称排版折行算法，优先撑满单行空间且智能保护版本号小数点（如 3.0、4.1），杜绝突兀腰斩折行，配合拓宽的 Y 轴标签使模型名称更易辨识；
- **设置面板交互与多语言体验修复**：修复语言下拉列表中跟随系统（System Default）的选中状态，统一子面板标题层级与间距，提升视觉一致性。
