# iRouter v0.3.2 Release Notes

[简体中文版本](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.3.2.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.2)

> **iRouter** is a cross-platform desktop client for the universal LLM routing gateway, deeply customized from [decolua/9router](https://github.com/decolua/9router). This release advances the gateway core baseline to official **v0.5.91**, brings complete Claude reasoning chain returns in OpenAI-compatible clients, completes Responses API terminal stream outputs, hardens Gemini terminal-turn boundary validation, optimizes large connection pool scheduling to O(1), and adds seamless Zed IDE credential discovery.

---

### 🌟 What's New in v0.3.2

#### 1. 🌐 Gateway Core Baseline Advanced to v0.5.91
- Fully aligned with official 9Router **v0.5.87 ~ v0.5.91** (50+ commits), significantly improving dispatch stability and fault tolerance across major LLM providers in high-concurrency environments.

#### 2. 🧠 Complete Claude Reasoning Returns in OpenAI-Compatible Mode
- Fixed and optimized the Claude-to-OpenAI reasoning translation pipeline.
- Accurately transmits full `reasoning_content`, solving the missing chain-of-thought issue in third-party OpenAI-compatible clients (e.g., Cherry Studio, Chatbox).

#### 3. 📦 Responses API Enhancements & `message.output` Terminal Streaming
- Deeply aligned with Responses API specifications, completing `message.output` streaming chunk encapsulation and terminal chunk signals.
- Resolves stream interruptions and missing completion states for advanced downstream clients relying on the Responses protocol.

#### 4. 🤖 Gemini Terminal-Turn Empty Content Guard
- Introduced strict guard-clause validation for empty terminal turns and content in the Gemini adapter.
- Eliminates upstream `400 InvalidArgument` errors and transformation crashes caused by empty trailing messages, greatly increasing resilience.

#### 5. ⚡ O(1) Large Connection Pool Scheduling Optimization
- Refactored internal connection pool indexing from linear scans to constant-time hash/bidirectional data structures.
- Reduced insertion and lookup complexity to $O(1)$, slashing CPU usage and latency during high-concurrency, long-lived streaming sessions.

#### 6. 🔑 Zed IDE Credential Auto-Discovery & Ecosystem Integration
- Added built-in auto-detection and import for Zed editor configuration credentials.
- Allows developers to seamlessly reuse their existing Zed IDE tokens and model configurations without manual copy-pasting.

#### 7. ⏳ Claude Rate-Limit Reset Tracking & Auto-Reset for Free Tier
- Integrated upstream rate limit reset clock mechanisms to accurately detect Claude's official reset windows.
- Automatically refreshes and resets free-tier account pools, maximizing quota availability and self-healing.

#### 8. 🔮 GPT-6 Sol/Luna & Next-Gen Model Specifications
- Pre-registered and normalized GPT-6 Sol, GPT-6 Luna, and next-generation model endpoints and metadata.
- Expanded context window bounds and token billing multipliers for upcoming proprietary and open-source models.

#### 9. 💎 100% Preservation of Proprietary Capabilities
- **Intelligent Retry & Backoff**: Retains configurable backoff jitter and cooldowns (`retryCfg`) for resilient client requests.
- **Outbound Data Loss Prevention (DLP)**: Outbound sensitive token/credential masking engine remains active.
- **Active Reasoning Effort Clamping (`effortCap`)**: Enforces reasoning effort limits on downstream models.
- **Combo 4xx Resilience**: Ensures single-model 4xx errors do not abort the entire combo fallback chain.
