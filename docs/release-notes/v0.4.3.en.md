# iRouter v0.4.3 Release Notes

[简体中文版本](https://github.com/kevinjoy89/iRouter/blob/v0.4.3/docs/release-notes/v0.4.3.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.3)

> **iRouter** is a cross-platform desktop client for an LLM routing gateway (lightweight Tauri v2 + Bun architecture).
> **v0.4.3 highlights**: cleaning up the items from the previous version that never took effect — the settings entry now actually appears after an upgrade, and a fresh install follows your system language. This release also fixes links that did nothing when clicked, tray icons that were invisible on dark taskbars, and the Windows installer's icon and language.

---

### 🌟 What's Changed

- **Some upgrades kept showing the old interface**: the settings entry added in the previous version was missing on Windows and Linux, with no error in the console. The gateway's page cache did not invalidate across builds, so after an in-place upgrade the browser still rendered the old interface. The gateway now clears the stale cache on startup once it detects a different build, so new interfaces take effect immediately;
- **First-launch language on a fresh install**: it used to be fixed to English instead of following the system. All three platforms now resolve it once as **explicit choice > system language > English**, so the tray menu and the panel can no longer end up in two different languages;
- **Fewer language options**: the list is now Simplified Chinese / Traditional Chinese / English. It previously offered 28 languages with no dictionary behind them, and picking one silently fell back to English;
- **Where settings live**: moved from the top-right corner of the header to the **bottom of the sidebar** with a text label, and "Settings…" in the tray menu is now the first item;
- **Missing translations** on the provider detail page and in the "Add custom model" panel: the leftover English there — card titles and input placeholders included — is now translated;
- **Outbound links**: the various external links on the provider detail page did nothing when clicked. They now open in your system browser, while the app window itself does not navigate away;
- **Tray icon**: it was nearly invisible on dark Windows taskbars and on Linux panels; colours are now chosen per platform;
- **Installer experience (Windows / Linux)**: the Windows package and uninstaller use the application icon again (they had been falling back to the installer's own default icon); the setup wizard now uses Chinese automatically on Chinese systems; the copyright line in the installer footer is no longer smudged; no extra black console window appears at runtime; and the Linux launcher shows a user-facing application name and summary.
