# iRouter v0.3.4 Release Notes

[简体中文版](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.3.4.zh-CN.md) | [GitHub Release](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.4)

> **iRouter** is a cross-platform desktop client for a large-model routing gateway, deeply customized from [decolua/9router](https://github.com/decolua/9router). This release rebuilds the **settings panel into a two-pane, sectioned layout** (Appearance / Window / Software Update / Network / Observability / Data Storage / Security / Gateway Settings), brings gateway storage governance and security settings under it, and fixes a **credential leak** plus **silently undercounted usage statistics**.

---

### 🌟 What's New in v0.3.4

#### 1. 🎛️ Two-Pane Settings Panel
- **From one long scroll to an index plus cards**: the panel used to stack eight groups in a 512px column (~3300px of content), so settings were hard to find and there was no sense of how much was left. Now the left pane indexes sections and the right pane scrolls independently.
- **Eight sections**: Appearance / Window / Software Update / Network / Observability / Data Storage / Security / Gateway Settings. Each section is its own file; a single section table drives both the nav and the content.
- **Unified controls**: switches (`role="switch"`, replacing bare native checkboxes), selects (native `<select>` with a custom arrow, keeping keyboard and screen-reader behaviour), inline notice bars, and stat tiles.
- **Unified footer**: app name, version, local/remote mode and update verdict merged into the panel footer; the sidebar no longer duplicates a "Gateway Settings" entry.

#### 2. 🔗 Embedded Gateway Settings & Standalone Security Section
- "Gateway Settings" no longer navigates away — the Profile page is rendered **natively** in the right pane, loaded on demand so it does not bloat every route's first-paint bundle.
- **Security** (require login / password / single sign-on OIDC + SAML) was split out of Gateway Settings into a sibling section.
- The endpoint page's security banners ("Open settings" / "Change password") now **land directly on that section** instead of dropping the user among unrelated cards.

#### 3. 🗄️ Data Storage: Location, Size and Retention in One Place
- **Data location first**: shows the SQLite file path (main file + WAL).
- **Four stat tiles**: database size / request-detail rows / oldest entry / max field size.
- **Retention in days**: rolling cleanup (at startup and every 6 hours) plus a manual "Save & clean now"; VACUUM / incremental reclaim stay out of the UI.
- **Configuration export / import** managed on the same page as location and retention.

---

### 🛡️ Security & Data-Integrity Fixes

#### 4. Usage API no longer returns plaintext API keys
- **Issue**: the `byApiKey` **object keys** of `GET /api/usage/stats` contained the complete client-side gateway API key (the write path keys buckets by the full key to avoid mask collisions), while the route returned the stats object verbatim — any authenticated dashboard session could read usable gateway credentials from the response.
- **Fix**: bucket names are rebuilt at the **response boundary** (key name + mask + model + provider). No secret is included, collisions are less likely than with the mask alone, the same key always derives the same bucket name, and the logic is a pure function covered by behavioural assertions.

#### 5. Parallel writes no longer drop usage records
- **Issue**: the write path deduplicated on "millisecond timestamp + request shape", so **distinct requests sharing that shape within the same millisecond were merged** — a stress test showed 100 parallel writes landing as 1, and 50 landing as 13. Usage statistics silently undercounted.
- **Fix**: dedup only ever existed to merge "the same request recorded first without, then with, an endpoint", so it is now narrowed to **merge only when it can complete a missing endpoint**: complementary records still merge, complete records each count.

#### 6. Icon sizes restored to their declared values
- **Issue**: the icon font package ships an **unlayered** `font-size: 24px` rule, and unlayered styles always beat layered ones — so every `text-[Npx]` in the codebase was inert (sidebar declared 18px, panel nav 17px, stat tiles 14px; all rendered at 24px).
- **Fix**: the font file now ships with the app and the icon base styles live in `@layer base`; icons render at their declared sizes, and icons without an explicit size stay at 24px.

---

### 💎 Local-Only Core Capabilities Fully Retained

- **Smart retry & backoff**: `retryCfg` retained (exponential backoff can be disabled; custom cooldown supported).
- **Outbound data redaction (DLP)**: detects and rewrites sensitive content before it reaches upstream (policy + exemption markers).
- **Thinking-effort clamping (`effortCap`)**: downstream thinking-effort clamping and boundary adaptation.
- **Combo cross-model 4xx failover**: a single model's 4xx does not break the multi-model failover chain.

> **macOS Gatekeeper Notice**:
> Since this is a personal open-source application without an Apple paid developer certificate (unsigned and un-notarized), macOS Gatekeeper may show a warning upon first launch. You can bypass it by:
> 1. In Finder -> Applications, **Right-click (or Control-click) iRouter -> Open -> click Open** in the prompt;
> 2. Or go to System Settings -> Privacy & Security -> Security, find the blocked entry and click "Open Anyway".
> This confirmation is only needed once on first launch; double-clicking works afterwards.
