# iRouter v0.3.7 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.3.7.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.7)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。
> 本版本（v0.3.7）为针对桌面端更新交互体验的重要缺陷修复版，重点修复了 macOS 菜单栏与系统托盘「检查更新」在存在新版本时无响应的问题，完善了原生提示弹窗与一键直达更新面板的交互链路。

---

### 🛠️ 缺陷修复与体验改进 (Bug Fixes & Improvements)

#### 1. 修复菜单栏与系统托盘检查更新无响应缺陷
- **问题现象**：在 macOS 应用菜单、帮助菜单以及系统托盘中点击「检查更新…」时，若当前已是最新版本能正常弹窗，但在远端有可用新版本时点击没有任何界面反馈与反应；
- **问题根因**：主进程手动检查更新逻辑中遗漏了新版本分支的原生交互处理，仅发送了 IPC 通知；且当设置面板未处于打开挂载状态时，前端无组件响应，导致操作断链；
- **改进修复**：完善主进程更新结果分流处理。在手动点击且发现新版本时，主动弹出原生系统对话框，明确展示当前版本与新版本号，并提供「打开更新面板」与「稍后」操作选项；若遇到网络异常或检查失败，同样弹出警告对话框友好提示。

#### 2. 打通设置面板目标分段一键直达链路
- **IPC 载荷透传**：打通 Electron 主进程 `openSettings(section)`、Preload 预加载层以及前端 `ShellSettingsHost` 目标分段传递链路；
- **更新面板直达**：在发现新版本对话框中点击「打开更新面板」时，系统自动调起主窗口、展开设置面板并精准定位至「软件更新」分段，方便直接查看更新日志并一键执行下载与安装。

#### 3. 补齐更新交互多语言国际化字典
- 在壳层菜单多语言字典（`en` / `zh-CN` / `zh-TW`）中补齐了发现新版本标题、详情说明、打开按钮以及检查失败警告的原生文案支持。

> **macOS 首次打开拦截提示**：
> 个人开源软件未购买苹果付费开发者证书，macOS Gatekeeper 可能会弹出“无法打开，因为无法验证开发者”的安全拦截。放行方式（二选一）：
> 1. 在「访达 -> 应用程序」中，**按住 Control 键右键点击 iRouter → 选择“打开” → 在弹窗中再次点击“打开”**；
> 2. 或进入「系统设置 → 隐私与安全性 → 安全性」，找到拦截记录点击「仍要打开」。
> 该操作仅在首次启动时需要确认一次，之后双击即可直接运行。
