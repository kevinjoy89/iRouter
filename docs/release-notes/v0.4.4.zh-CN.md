# iRouter v0.4.4 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/v0.4.4/docs/release-notes/v0.4.4.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.4)

> **iRouter** 是跨平台的大模型路由网关桌面客户端（Tauri v2 + Bun 轻量架构）。
> **v0.4.4 核心重点**：全面对齐上游 9router `v0.5.104` 网关基线，引入 Nous 提供商与多项协议兼容增强；同时优化设置面板高度与配额卡片排版，全面补全多语言国际化翻译。

---

### 🌟 核心变化

- **上游网关基线对齐至 v0.5.104**：底座从 `v0.5.99` 升级至 `v0.5.104`，完整同步上游协议能力与安全修复。产品版本号（v0.4.4）与上游基线号（v0.5.104）继续保持独立解耦演进，桌面端自研增强不受上游变动影响；
- **新增 Nous 提供商支持**：同步上游新增的 Nous 接入支持，涵盖 OAuth 授权、能力解析、模型路由与用量统计；
- **上游模型协议与路由能力增强**：同步上游对 Claude（上下文管理与空思考块规整）、Cursor（Agent 请求代理与用量）、OpenCode 及 Vertex 区域适配等多项协议层改进，模型搜索与去重更精准；
- **设置面板切换不再跳动**：设置面板高度重构为统一规格，在通用、网络、安全等不同子菜单之间切换时，弹窗高度不再随内容长短而上下抖动；切换选项时右侧内容自动回到顶部，浏览更流畅；
- **配额列表排版更紧凑**：配额卡片默认调整为每页展示 3 条，并将底部分页栏收敛为单行图标按钮，避免纵向过度占用屏幕空间；
- **使用统计图表文字更清晰**：图表能够准确识别并展示自定义节点与兼容提供商的友好名称；热门模型名称取消左侧裁切并支持左对齐自动换行，图表更易阅读；
- **多语言国际化全面补全**：补齐面包屑导航、配额重置周期、上下文压缩提示、服务徽标与提供商说明的多语言翻译，消除未译英文与碎片拼接。
