# iRouter v0.3.3 Release Notes

[简体中文版本](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.3.3.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.3)

> **iRouter** is a cross-platform desktop client for the universal LLM routing gateway, deeply customized from [decolua/9router](https://github.com/decolua/9router). This release officially introduces the **comprehensive in-app auto-updater suite**, including intelligent version detection, platform-aware binary asset matching, real-time download progress with instant cancellation, cryptographic SHA-256 checksum verification against tampering, and automated native installer launch, while retaining 100% of proprietary core gateway capabilities.

---

### 🌟 What's New in v0.3.3

#### 1. 🚀 In-App Auto-Updater Suite
- **Multi-Scene Entry Points**: Added dedicated update status and trigger controls within the Settings panel, alongside quick "Check for Updates" actions in the macOS app menu, Windows/Linux native menu bars, and system tray context menus.
- **Silent Background Checks on Launch**: Automatically performs an unobtrusive background check upon startup with delayed timing, alerting the user via lightweight system notifications only when an update is available.
- **User-Controlled Automation**: Users can toggle "Check for updates on launch" within Settings. Configurations are cleanly persisted in `~/.irouter/shell-settings.json`.

#### 2. 🎯 Platform-Aware Asset Matching & Graceful Fallback
- **Exact Multi-Architecture Alignment**: Automatically identifies the host OS and architecture (macOS Apple Silicon arm64 / Intel amd64, Windows installer exe / portable zip, Linux deb / tar.gz) and maps directly to the appropriate GitHub Release assets.
- **Seamless Browser Fallback**: Gracefully provides direct navigation links to GitHub Releases if running under non-standard configurations, preventing execution lockups.

#### 3. 📥 Streaming Download Progress & Safe Cancellation
- **Live Progress Feedback**: The download pipeline follows cross-domain redirects (302) and computes received bytes, total size, and completion percentage in real time, rendered smoothly in the UI progress bar.
- **Cancellable with Clean Cleanup**: Users can cancel downloads at any point. Cancelled or aborted downloads immediately clean up incomplete temporary artifacts (`*.download`), preventing disk clutter.

#### 4. 🛡️ Cryptographic SHA-256 Checksum Verification
- **Automated Checksum Fetching**: Concurrently retrieves and normalizes official `checksums.txt` manifests during asset downloads.
- **Strict Anti-Tampering Defense**: Streams and verifies SHA-256 hashes locally upon download completion. Corrupted, truncated, or tampered assets are strictly blocked, alerted, and purged before execution.

#### 5. ⚡ Seamless OS-Native Installation Launch
- **macOS**: Automatically mounts and displays the DMG volume upon successful verification, presenting the native "Drag to Applications" dialog.
- **Windows**: Directly executes `.exe` installers or opens and highlights extracted `.zip` portable directories.
- **Linux**: Opens the download directory or invokes default package managers for `.deb` and `.tar.gz` packages.

#### 6. 🌐 Complete Multi-Language (i18n) Support
- Fully integrated with the application's internationalization engine across all lifecycle states.
- Seamlessly switches between English and Simplified Chinese for states including "Checking for updates", "You're up to date", "Update available", "Downloading (xx%)", "Verifying integrity", and "Checksum mismatch warnings".

#### 7. 💎 100% Preservation of Proprietary Capabilities
- **Intelligent Retry & Backoff**: Retains configurable backoff jitter and cooldowns (`retryCfg`) for resilient client requests under rate limits.
- **Outbound Data Loss Prevention (DLP)**: Outbound sensitive token/credential masking engine remains active.
- **Active Reasoning Effort Clamping (`effortCap`)**: Enforces reasoning effort limits on downstream models.
- **Combo 4xx Resilience**: Ensures single-model 4xx errors do not abort the entire combo fallback chain.
