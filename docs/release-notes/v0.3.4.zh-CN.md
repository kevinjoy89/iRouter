# iRouter v0.3.4 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.3.4.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.4)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。本版本把**设置面板重构为双栏分段式**（外观 / 窗口 / 软件更新 / 网络设置 / 可观测性 / 数据存储 / 安全设置 / 网关设置），把网关的存储治理与安全设置一并纳管，并修复了一个**凭据泄露**与一个**使用量统计静默少算**的问题。

---

### 🌟 核心更新亮点 (What's New in v0.3.4)

#### 1. 🎛️ 设置面板重构：双栏分段式 (Two-Pane Settings Panel)
- **从「一条长滚动」到「左栏索引 + 右栏卡片」**：此前是 512px 窄列里堆着八个分组（实测内容高约 3300px），既找不到设置、也不知道还剩多少；现在左栏分段索引、右栏独立滚动。
- **八个分段**：外观 / 窗口 / 软件更新 / 网络设置 / 可观测性 / 数据存储 / 安全设置 / 网关设置，每段独立成文件，一张分段表同时驱动导航与内容。
- **控件统一**：开关（`role="switch"`，替掉裸露的原生 checkbox）、下拉（原生 select + 自绘箭头，键盘与读屏不受影响）、状态条（图标 + 语气色）、读数瓦片。
- **页脚统一**：应用名、版本号、本地/远程模式与更新结论合并到面板页脚；侧栏不再重复「网关设置」入口。

#### 2. 🔗 网关设置原生嵌入 + 安全设置独立成段 (Embedded Gateway & Standalone Security)
- 「网关设置」不再跳转页面，而是把 Profile 页**原生嵌入**右栏；用按需动态加载，避免把这一大页打进每个路由的首屏 bundle。
- **安全设置**（登录要求 / 密码 / 单点登录 OIDC + SAML）从网关设置里拆出，成为平级的独立分段。
- 端点页的安全横幅（「打开设置」/「改密码」）点击后**直达该分段**，不再把用户丢在无关卡片中间。

#### 3. 🗄️ 数据存储：位置、体积与保留策略集中管理 (Data Storage)
- **数据位置置顶**：直接显示 SQLite 文件路径（主文件 + WAL）。
- **四个读数瓦片**：库体积 / 请求详情条数 / 最早记录 / 单字段上限。
- **保留详情天数**：滚动清理（启动后与每 6 小时各一次），支持手动「保存并立即清理」；底层虽有 VACUUM/增量回收，但这类概念不出现在界面上。
- **配置文件导出 / 导入**：与数据位置、保留策略同页管理。

---

### 🛡️ 安全与数据完整性修复 (Security & Data Integrity)

#### 4. 用量接口不再回传明文 API key
- **问题**：`GET /api/usage/stats` 的 `byApiKey` 对象**键名**含完整客户端网关 API key（写路径用完整 key 作桶名，以避免掩码把同前缀的 key 并成一桶），而该接口把统计对象原样 JSON 化返回前端 —— 任何已登录面板的会话都能在响应里读到可用的网关凭据。
- **修复**：在**响应边界**重建桶名（密钥名称 + 掩码 + 模型 + 供应商）。不含密钥、比「只用掩码」更不易撞桶、同一个 key 稳定派生出同一个桶名；逻辑抽成纯函数并补行为断言。

#### 5. 并行写入不再丢使用量记录
- **问题**：写入路径按「毫秒时间戳 + 请求形状」去重，于是**同一毫秒内形状相同的不同请求被并成一条** —— 压测实测 100 条并行只落 1 条、50 条落 13 条，使用量统计静默少算。
- **修复**：去重的本意只是「同一次请求先缺 endpoint、后补上」时合并，故收窄为**只在能补全缺失 endpoint 时才合并**：互补记录仍合并，完整记录各算各的。

#### 6. 图标尺寸恢复各自声明的值
- **问题**：图标字体包自带的 `font-size: 24px` 处于**未分层**样式（层叠里未分层永远赢过分层），把全仓的 `text-[Npx]` 全部压掉了 —— 侧栏声明 18px、面板导航 17px、读数瓦片 14px，实测一律渲染成 24px。
- **修复**：字体文件改为随应用分发，图标基础样式整体放进 `@layer base`，各处图标恢复声明的尺寸，未指定尺寸的图标仍是 24px。

---

### 💎 本地专有核心能力 100% 完整保留

- **智能重试与退避机制**：保留 `retryCfg`（支持禁用指数退避与自定义冷却时间）。
- **出站数据脱敏 (DLP)**：转发上游前检测并改写敏感内容（脱敏策略与豁免标记）。
- **思考强度主动钳制 (`effortCap`)**：下游请求思考强度钳制与边界适配。
- **Combo 跨模型 4xx 容灾**：单模型 4xx 不阻断多模型容灾重试链。
