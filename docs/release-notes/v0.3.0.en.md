# iRouter v0.3.0 Release Notes

[简体中文版本](v0.3.0.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.0)

> **iRouter** is a cross-platform desktop client for the universal LLM routing gateway, deeply customized from [decolua/9router](https://github.com/decolua/9router). This release updates the gateway core baseline to upstream official **v0.5.81**, introduces a comprehensive automated multi-platform build matrix, and standardizes open-source licensing, project documentation, and engineering dependencies.

---

### 🌟 What's New in v0.3.0

#### 1. 🌐 Gateway Core Baseline Advanced to v0.5.81
- **Full Upstream Alignment**: Synchronized all gateway features from official 9Router **v0.5.81** (over 100+ commits).
- **Xiaomi MiMo Desktop Integration**: Adapted Xiaomi MiMo desktop application login session workflows and dedicated model routing.
- **Claude Code 1M Context Window**: Added Claude Code 1M context markers, token accounting, and graceful capture of streaming refusal frames.
- **DeepSeek V4.1 Flash**: Fully integrated vision and long-context capabilities for DeepSeek-V4.1-Flash.
- **OpenCode Stability & Anti-Blocking**: Resolved frequent 403 anti-bot blocks, 429 session retries, and prior-turn encrypted reasoning token conflicts.

#### 2. 🏗️ Standardized Multi-Platform Build Matrix
- **Automated Packaging Workflow**: Powered by GitHub Actions matrix builds supporting fine-grained architectures and distribution formats:
  - **macOS**: Native Apple Silicon (`arm64.dmg`) and Intel (`amd64.dmg`).
  - **Windows**: Standard NSIS installer (`installer.exe`) and portable standalone archive (`portable.zip`).
  - **Linux**: Native Debian/Ubuntu package (`amd64.deb`) and standalone tarball (`amd64.tar.gz`).
- **Consolidated Integrity Verification**: Every release automatically provides `checksums.txt` containing SHA-256 hashes for all downloadable assets.

#### 3. ⚖️ Open-Source Compliance & Documentation
- **MIT Licensing**: Formally established the **MIT License** in the repository root, preserving upstream copyrights and derivative licensing terms.
- **Bilingual Documentation**: Restructured official documentation into English [`README.md`](../../README.md) and Simplified Chinese [`README.zh-CN.md`](../../README.zh-CN.md).
- **Community Acknowledgements**: Added formal credits to `decolua/9router` and `momijineko/llm-retry-proxy` for foundational gateway architecture and retry/DLP inspiration.

#### 4. 🪶 Engineering Pruning & Desktop Focus
- **Removed Docker Pipeline**: Cleaned up historical Dockerfile, docker-compose, and container publishing workflows, reducing desktop maintenance overhead to deliver a clean, native experience.

---

### 💎 Proprietary Features Preserved

- 🔄 **Intelligent Retry & Resilience (ADR 0004/0005)**:
  - Intercepts network glitches and rate-limit errors (`429`, `503`, `529`) before time-to-first-token (TTFT), performing jittered exponential backoffs.
  - In-place account retries, sticky affinity, and dynamic 429 cooldown locking to protect CLI agent stability.
- 🛡️ **Outbound Data Loss Prevention (DLP, ADR 0005)**:
  - Pre-flight sensitive token/credential masking engine for API keys, private keys, citizen IDs, and payment cards.
  - Fail-Open safety guarantee with intelligent code-syntax false positive suppression.
- 📊 **Persistent Usage Logging & Real-time Auto-refresh**:
  - Full request audit trails stored locally in SQLite across restarts.
  - Rolling 24-hour time window with high-frequency auto-refresh and status code filtering.
- 📜 **High-Performance Virtual Scrolling Console**:
  - Variable-height virtual scrolling engine ensuring smooth rendering even with massive log volumes.
- 🔒 **Isolated Data Storage Directory**:
  - Core database and configs persisted in `~/.irouter`, completely decoupled from application caches.
  - One-click migration wizard on first run to import configurations from legacy CLI `~/.9router`.

### 🔌 API Endpoint & Local Setup

iRouter Desktop and the OpenAI-compatible gateway share the same local port:

```text
API Endpoint:  http://127.0.0.1:20128/v1
API Key:       Copy directly from the iRouter desktop dashboard
```
*Port Fallback: If port 20128 is already occupied, iRouter automatically increments to the next available port (e.g. 20129) without terminating existing processes.*
