# iRouter v0.4.2 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.4.2.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.2)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端（采用 Tauri v2 + Bun 轻量架构）。  
> **v0.4.2 核心重点**：重构并精简壳层设置面板架构（方案 A），全面补全端点、组合、配额、CLI 工具及 System One 的多语言国际化与动态正则匹配，并加固预渲染构建流水线。

---

### 🌟 核心变化与亮点

#### 1. 壳层设置面板架构重构（方案 A）

- **全新「通用 (General)」分段置顶**：
  - 将原「外观」与「窗口」分段合并，作为左栏第一项；
  - 整合主题外观、界面语言偏好与桌面壳关窗/开机自启行为；
  - 外观主题选项中将「跟随系统 (Follow system)」调整到第 1 位。
- **全新「数据与日志 (Data & Logs)」分段**：
  - 合并原「可观测性」与「数据存储」分段，一站式管理控制台日志开关、数据库存储指标、数据保留天数及网关配置备份与还原。
- **导航顺序优化**：
  - 菜单结构调整为：通用 (General) → 网络 (Network) → 数据与日志 (Data & Logs) → 安全 (Security) → 网关设置 (Gateway Settings) → 软件更新 (Software Update)；
  - 「软件更新」移至菜单末项，同时保留更新发现红点提示。

#### 2. 全面板 i18n 补全与动态正则国际化

- **端点与密钥页面**：
  - 补全密钥组合/模型访问控制白名单标签（`Allowed for "..."`）；
  - 补全快捷限制访问确认弹窗文案（`Restrict API key "..."?`）。
- **组合与视觉适配器页面**：
  - 补全批量全选与计数（`Select all (N)`、`N selected`）；
  - 修复 `code` 标签导致的上下文指标跳过翻译问题，补全 `ctx ...`、`max ...`、`+N more` 及 `Auto — ...`；
  - 补全池为空故障转移提示（`No models in pool (will fallback to ...)`）。
- **配额跟踪器与使用情况**：
  - 补全配额倒计时与过期提示（`in Xd Xh Xm`、`expires in ...`）；
  - 补全福利包与赠送包文案（`Bonus Pack N`）。
- **命令行工具与 System One**：
  - 补全工具检测状态（`Checking ...`、`... not detected locally`、`... Configuration`）；
  - 补全媒体与 System One 内部提供商管理文案。

#### 3. 生产构建与预渲染稳定性加固

- 修正设置面板内部组件导入依赖，消除 Next.js 静态页面预渲染（prerender）构建异常；
- 单元测试与国际化守护用例全量通过（49/49）。
