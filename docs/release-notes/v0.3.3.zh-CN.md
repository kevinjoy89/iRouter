# iRouter v0.3.3 发版说明 (Release Notes)

[English Version](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.3.3.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.3)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。本版本正式推出**应用内更新全套机制**，涵盖版本智能检测、跨平台二进制资产精准匹配、下载实时进度反馈与随时可取消、强加密 SHA-256 完整性校验防篡改以及全平台原生安装自动引导，同时保留网关核心的高并发调度与模型适配能力。

---

### 🌟 核心更新亮点 (What's New in v0.3.3)

#### 1. 🚀 应用内智能更新全链路打通 (In-App Auto-Updater)
- **多场景入口覆盖**：在「设置中心」新增专属更新控制面板与即时状态反馈；在 macOS 顶栏菜单、Windows/Linux 应用菜单以及系统托盘右键菜单中均新增「检查更新」快捷入口。
- **启动时静默检查**：支持应用启动后延迟在后台静默发起版本检查；若检测到新版本，将通过系统轻量气泡提醒用户，不打扰正在进行的工作。
- **自主控制开关**：用户可在设置中心自由开启或关闭「启动时自动检查更新」，配置持久化于本地 `~/.irouter/shell-settings.json`，充分尊重用户使用偏好。

#### 2. 🎯 跨平台产物精准匹配与智能回退 (Platform-Aware Asset Matching)
- **多架构精准对齐**：根据当前系统的操作系统与 CPU 架构（macOS Apple Silicon arm64 / Intel amd64、Windows installer exe / portable zip、Linux deb / tar.gz），自动解析并匹配 GitHub Release 发布的对应二进制资产。
- **平滑兼容回退**：若遇到非标准环境或未匹配到直接安装包，系统自动提供跳转至 GitHub Release 页面的回退链接，避免逻辑死锁。

#### 3. 📥 流式下载进度反馈与可控取消 (Download Progress & Cancellation)
- **实时进度感知**：下载管道支持跨域名 302 重定向跟随，实时计算接收字节数、总文件大小及下载百分比，并在前端弹窗中以平滑进度条直观呈现。
- **可控取消与无损清理**：用户可随时中止下载流程；取消或异常中断时，系统自动清理临时文件（`*.download`），杜绝垃圾碎片占用磁盘空间。

#### 4. 🛡️ SHA-256 完整性与安全防篡改校验 (Cryptographic Checksum Verification)
- **自动抓取校验凭据**：在下载安装包的同时，自动获取官方发布的 `checksums.txt` 校验和文件，并针对不同哈希格式进行规范化解析。
- **严格安全拦截防线**：安装包下载完成后在本地流式计算 SHA-256 哈希值并与官方凭据比对。若哈希不符，系统将立即阻断流程、发出安全告警并自动粉碎异常文件，彻底隔绝网络劫持、中间人攻击或网络截断损坏风险。

#### 5. ⚡ 全平台原生安装拉起与引导 (Seamless OS-Native Installation)
- **macOS**：下载校验成功后自动挂载并打开 DMG 镜像，直观唤起「拖拽至 Applications」原生安装窗口。
- **Windows**：安装程序（.exe）支持一键拉起安装向导，便携版（.zip）自动打开目标文件夹并定位高亮。
- **Linux**：自动拉起目标文件所在目录或系统默认的包管理器执行安装。

#### 6. 🌐 完善的中英双语本地化支持 (Complete i18n Localization)
- 设置中心更新组件与交互流程深度接入应用的多语言系统（`i18n`）。
- 涵盖“正在检查更新”、“已是最新版本”、“发现新版本”、“下载中 (xx%)”、“正在校验完整性”、“校验失败告警”等全部生命周期状态文案，支持简体中文与英文无缝切换。

#### 7. 💎 本地专有核心能力 100% 完整保留
- **智能重试与退避机制**：保留 `retryCfg`（支持禁用指数退避与自定义冷却时间），提升弱网与模型突发限流场景下的抗抖动能力。
- **出站数据脱敏 (DLP)**：严格保障出站数据安全过滤与敏感密钥改写，防止凭据外泄。
- **思考强度主动钳制 (`effortCap`)**：支持下游请求思考强度钳制与边界适配，兼顾高兼容性与模型成本控制。
- **Combo 跨模型 4xx 容灾**：单模型 4xx 不阻断多模型容灾重试链。

> **macOS 首次打开拦截提示**：
> 个人开源软件未购买苹果付费开发者证书，macOS Gatekeeper 可能会弹出“无法打开，因为无法验证开发者”的安全拦截。放行方式（二选一）：
> 1. 在「访达 -> 应用程序」中，**按住 Control 键右键点击 iRouter → 选择“打开” → 在弹窗中再次点击“打开”**；

> 该操作仅在首次启动时需要确认一次，之后双击即可直接运行。
