# iRouter v0.3.7 Release Notes

[简体中文 (Chinese Version)](v0.3.7.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.7)

> **iRouter** is a cross-platform desktop application for the LLM router gateway based on [decolua/9router](https://github.com/decolua/9router).
> Release v0.3.7 is an essential bugfix release focusing on desktop in-app update interaction, fixing the unresponsive "Check for Updates" issue in the macOS menu bar and system tray when a new version is available.

---

### 🛠️ Bug Fixes & Improvements

#### 1. Fix Unresponsive Update Checks from Menu Bar and System Tray
- **Symptom**: Clicking "Check for Updates…" from the macOS app menu, help menu, or system tray would show the up-to-date dialog when on the latest version, but did nothing when a new version was available;
- **Root Cause**: The main process update check omitted native dialog handling for the `updateAvailable` branch, only sending an IPC message. When the settings modal was not mounted, the event was silently missed;
- **Fix**: Enhanced update check branching in the main process. When manually checking and a new version is found, a native dialog displays version details and prompts to "Open Settings" or "Later". Network errors now also present an error alert.

#### 2. Direct Navigation to Software Update Section
- **IPC Payload Pass-Through**: Passed target section payloads through the Electron main process `openSettings(section)`, preload bridge, and frontend `ShellSettingsHost`;
- **One-Click Navigation**: Clicking "Open Settings" in the update prompt automatically brings the main window to front, opens the settings modal, and jumps directly to the "Software Update" section.

#### 3. Complete i18n Menu Translations
- Added localized translations for new version alerts, section navigation buttons, and check failures in English, Simplified Chinese, and Traditional Chinese.
