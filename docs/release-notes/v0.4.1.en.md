# iRouter v0.4.1 Release Notes

[简体中文版](https://github.com/kevinjoy89/iRouter/blob/main/docs/release-notes/v0.4.1.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.4.1)

> **iRouter** is a customized cross-platform LLM routing gateway desktop client based on [decolua/9router](https://github.com/decolua/9router) (powered by Tauri v2 + Bun).  
> **v0.4.1 Highlights**: Gateway baseline upgraded to 9Router **v0.5.99**, introducing fine-grained API Key access controls and MiniMax Code integration while retaining 100% of local customizations (DLP redaction, smart retry, thinking effort capping) with a fully green CI/CD pipeline across all platforms.

---

### 🌟 Key Changes & Improvements

#### 1. Gateway Baseline Upgraded to 9Router `v0.5.99`

- **Fine-Grained API Key Access Control (KeyAccessControls)**:
  - Restrict allowed Combo groups and models per individual API Key;
  - Enforced across `/v1/chat/completions`, `/v1/messages`, `/v1/responses`, multimodal endpoints, and model catalog discovery;
  - Front-loaded check prior to bypass logic and credential resolution, with failover preserved for permitted combos.
- **New Providers: MiniMax Code & MiniMax Code Global**:
  - Full support for developer API keys and OAuth tokens with native Anthropic protocol emulation;
  - Automatic injection of Mavis session identifiers and local timezone offsets;
  - Adaptive reasoning effort mapping (`claude-adaptive`).
- **Provider Ecosystem Expansion**:
  - Added Kimchi aggregation and OAuth deduplication;
  - Added Self-hosted TTS placeholder and configuration support;
  - Enhanced nested thinking block translations across Gemini, Claude, and Responses protocols.
- **Upstream Bug Fixes & Hardening**:
  - Aligned GLM-5.3 series 1M default context window and non-disableable thinking behavior;
  - Improved Cursor live model discovery with resilient fail-open fallback;
  - Refined CLI connect configuration inheritance and tool isolation.

#### 2. Local Customizations 100% Retained & Integrated

- **Outbound Data Loss Prevention (DLP)**: Real-time sensitive data scanning and rule-based redaction with comprehensive audit logs;
- **Smart Retry & Backoff (`autoRetry`)**: Exponential backoff and retry handling for rate limits (429), transient gateway errors (500/502/503/504), and upstream error messages;
- **Active Reasoning Effort Capping (`effortCap` / `capped`)**: Local upper-bound clamp integrated with upstream thinking effort configurations;
- **Full Request Details Persistence**: Comprehensive telemetry retention with background compaction and offline vacuuming;
- **Zero Promotion Pollution**: Strictly excluded 9Remote promotional links and donation dialogs.

#### 3. Cross-Platform CI/CD & Test Automation

- Fully mocked HTTP/2 networking in unit tests to eliminate external dependencies and timeouts;
- Isolated `XDG_CONFIG_HOME` environment variables for consistent test execution on Linux;
- 100% passing GitHub Actions CI matrix (Ubuntu Regression Gate, Windows / macOS / Ubuntu smoke builds).
