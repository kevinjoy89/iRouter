# iRouter v0.3.1 Release Notes

[简体中文版本](v0.3.1.zh-CN.md) | [GitHub Release Page](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.1)

> **iRouter** is a cross-platform desktop client for the universal LLM routing gateway, deeply customized from [decolua/9router](https://github.com/decolua/9router). This release advances the gateway core baseline to official **v0.5.86**, significantly enhances anti-abuse fingerprinting and disaster recovery for providers like OpenCode and Qoder, introduces multi-dimensional usage analytics (Tokens / Requests / Cost) and combo capability aggregation, while firmly eliminating commercial promotional links to keep the client clean, lightweight, and focused.

---

### 🌟 What's New in v0.3.1

#### 1. 🌐 Gateway Core Baseline Advanced to v0.5.86 (Clean & Focused)
- Fully aligned with official 9Router **v0.5.86** (50+ commits and 20 new test suites), improving dispatch stability across major LLM providers.
- **Excluded Commercial Promotions & Bloat**: Firmly stripped 9Remote and 9English promotional entries/badges, removed unnecessary Docker pipelines, and pruned unrelated documentation to maintain a distraction-free desktop experience.

#### 2. 🛡️ OpenCode Free-Tier Fingerprint Protection & Request Sanitization
- **Automatic Fingerprint Tool Cloaking**: Auto-injects the required tool quartet (`bash`, `glob`, `grep`, `read`) into OpenCode Responses requests, reliably resolving the upstream `403 FreeTierError` blocks.
- **1.3-Free Auto-Normalization**: Demotes missing or unsupported `tool_choice` parameters on `muse-spark-1.3-contributor-free` to `"auto"`.
- **Encrypted Reasoning Cleanup**: Automatically purges prior-turn encrypted reasoning blobs (`encrypted_content`) to prevent `400` errors caused by upstream cross-turn verification failures.

#### 3. 🔄 Qoder 403 Rate-Limit Pass-Through & Failover
- Fixed an issue in the SSE-to-JSON handler where 403 rate-limit status codes were dropped. True upstream status codes are now preserved, properly triggering health cooldowns and automated account/provider failovers.

#### 4. 🔀 Combo Capability Aggregation & Conservative Window Bounds
- Integrated `aggregateComboCapabilities` to expose standardized `context_length` and `max_completion_tokens`.
- **Weakest-Link Conservative Strategy**: Uses the minimum context window among constituent models to prevent premature truncation; enhanced edge-case robustness for object-shaped members and whitespace-only IDs.

#### 5. 📊 Multi-Dimensional Usage Dashboard (Tokens / Requests / Cost)
- Usage charts now support real-time toggling across **Tokens**, **Requests**, and **Cost** metrics.
- Optimized multi-column responsive grid and dynamic metric formatting for clearer visualization.

#### 6. 🌍 Dynamic I18n Node Tracking
- Added `_translated` and `_originalText` attributes to the internationalization runtime to eliminate duplicate translations and visual flickering during dynamic DOM updates.

#### 7. 🔌 Provider & Ecosystem Expansion
- Added SystemOne multimodal media gateway pipeline.
- Integrated the Kimchi free-tier provider with dynamic model discovery.
- Aligned Claude CLI User-Agent snapshot with `2.1.280`.
- Fixed GLM-5.2+ reasoning effort mapping for Z.ai format (`reasoning_effort`).

#### 8. 💎 100% Preservation of Proprietary Capabilities
- **Intelligent Retry & Backoff**: Retains configurable backoff jitter and cooldowns (`retryCfg`) for resilient client requests.
- **Outbound Data Loss Prevention (DLP)**: Outbound sensitive token/credential masking engine remains active.
- **Active Reasoning Effort Clamping (`effortCap`)**: Enforces reasoning effort limits on downstream models.
- **Combo 4xx Resilience**: Ensures single-model 4xx errors do not abort the entire combo fallback chain.

### 🔌 API Endpoint & Local Setup

iRouter Desktop and the OpenAI-compatible gateway share the same local port:

```text
API Endpoint:  http://127.0.0.1:20128/v1
API Key:       Copy directly from the iRouter desktop dashboard
```
*Port Fallback: If port 20128 is already occupied, iRouter automatically increments to the next available port (e.g. 20129) without terminating existing processes.*
