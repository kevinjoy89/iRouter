# iRouter v0.3.1 发版说明 (Release Notes)

[English Version](v0.3.1.en.md) | [GitHub Release 页面](https://github.com/kevinjoy89/iRouter/releases/tag/v0.3.1)

> **iRouter** 是基于 [decolua/9router](https://github.com/decolua/9router) 深度定制的跨平台大模型路由网关桌面客户端。本版本将网关核心源码基线推进至官方 **v0.5.86**，全面增强对 OpenCode、Qoder 等主流供应商的防风控与容灾能力，并引入用量多维看板与 Combo 组合能力聚合，同时坚决剔除商业推广入口，保持客户端的纯净与专注。

---

### 🌟 核心更新亮点 (What's New in v0.3.1)

#### 1. 🌐 网关核心基线升级至 v0.5.86（去芜存菁，纯净专注）
- 全量吸收官方 9Router **v0.5.86**（覆盖 50+ 提交与 20 个新增测试套件），全面增强各主流供应商的调度稳定性。
- **坚决排除第四梯队内容**：彻底阻断 9Remote / 9English 商业推广入口与徽标，移除无关 Docker 流水线与冗余外部文档，保持 iRouter 桌面端轻量、纯净、无打扰。

#### 2. 🛡️ OpenCode Free-Tier 强防风控指纹与响应处理
- **指纹诱饵工具自动注入**：针对 OpenCode Responses 请求强制注入 `bash`、`glob`、`grep`、`read` 四件套诱饵指纹工具，彻底规避近期官方免费池频繁出现的 `403 FreeTierError` 拦截。
- **1.3-Free 降级与 auto 规范化**：针对 `muse-spark-1.3-contributor-free` 模型，自动将缺省或非法 `tool_choice` 降级为 `"auto"`。
- **跨轮次凭证清理**：自动过滤上一轮次残留的加密推理凭证（`encrypted_content`），避免历史上下文冲突导致的 `400` 报错。

#### 3. 🔄 Qoder 403 限流状态码真实透传与故障转移
- 修复 SSE 转 JSON 解析器在遇到 403 限流响应时丢弃真实状态码的缺陷，确保上游状态码原样穿透到调度器，精准触发供应商与账号维度的健康冷却与自动故障转移（Fallback）。

#### 4. 🔀 Combo 组合模型能力聚合与保守窗口计算
- 接入能力聚合算法（`aggregateComboCapabilities`），对外标准暴露 `context_length` 与 `max_completion_tokens`。
- **木桶原则保守策略**：自动提取成员最小上下文窗口，防止客户端盲猜或超窗截断；本地增强边界兼容性，支持对象成员和空白标识过滤。

#### 5. 📊 用量分析看板升级（Tokens / Requests / Cost 三模式切换）
- 用量分析图表支持 Tokens、Requests、Cost 三种维度的即时无缝切换查看。
- 优化大数字自适应排版及多列网格布局，展示更清晰直观。

#### 6. 🌍 国际化与多语言动态追踪优化
- 国际化内核增加 `_translated` 与 `_originalText` 动态追踪，彻底解决 DOM 动态更新节点时的重复翻译与闪烁问题。

#### 7. 🔌 供应商与生态扩展
- 接入 SystemOne 多模态媒体网关处理链路。
- 接入 Kimchi 免登供应商（Free-tier 免费额度池）及动态模型发现。
- 对齐 Claude CLI UA 快照至最新 `2.1.280`。
- 修复 GLM-5.2+ 思考强度映射与 z.ai `reasoning_effort` 支持。

#### 8. 💎 本地专有核心能力 100% 完整保留
- **智能重试与退避机制**：保留 `retryCfg`（支持禁用指数退避与自定义冷却时间），提升弱网抗抖动能力。
- **出站数据脱敏 (DLP)**：严格保障出站数据安全过滤，敏感信息不外泄。
- **思考强度主动钳制 (`effortCap`)**：支持下游请求思考强度钳制，防止模型超额开销。
- **Combo 跨模型 4xx 容灾**：单模型 4xx 不阻断多模型容灾重试。

### 📋 完整版本演进历史

#### 🚀 v0.3.1 (2026-09-24) — 当前最新发布
- 推进网关基线至 **v0.5.86**（OpenCode 指纹防御、Qoder 403 穿透、SystemOne 媒体、Kimchi 供应商接入）。
- 支持用量分析看板 Tokens / Requests / Cost 三模式切换。
- 支持 Combo 聚合能力与保守上下文窗口计算。
- 彻底剔除第四梯队商业推广入口，保持客户端纯净度。

#### 📦 v0.3.0 (2026-09-23)
- 上游基线全量同步至 **v0.5.81**。
- 标准化多平台构建矩阵，全面支持细分芯片架构与多发行格式。
- 开源合规规范化与轻量化工程整改。

#### ⚡ v0.2.6 ~ v0.2.10
- 请求详情表格 Card 顶层一体化工具条；支持近 24 小时动态实时滚动刷新并保留历史区间锁定；流式请求 Token 与 TTFT 结算优化；账号原地重试与 429 冷却配置。

#### 🛡️ v0.2.0 ~ v0.2.3
- OpenCode 免费端点风控拦截防御、自定义提供商配置、Combo 元数据解析及用量拓扑动效图视口漂移缺陷修复。

#### 🖥️ v0.1.0 ~ v0.1.9
- 桌面壳层设置面板模态框、出站请求敏感信息脱敏 (DLP) 引擎、版本号解耦（ADR 0004）、完整异常日志开关。

### 🔌 API 端点与本地配置

iRouter 桌面面板与 OpenAI 兼容 API 共享本地端口：

```text
API 端点:  http://127.0.0.1:20128/v1
API 密钥:  直接在 iRouter 桌面控制面板中点击复制
```
*端口顺延机制：若 20128 端口已被外部占用，iRouter 会自动顺延至下一个可用端口（如 20129），绝不强杀外部进程。*
